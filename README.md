# DBMS Question Paper (React + Vite)

```bash
npm install
npm run dev       # local dev server
npm run build     # production build in dist/
```

Edit the questions, CO/BT tags and key in `src/data.js`.

## Deploy to GitHub Pages
1. Push this project to a GitHub repo (branch `main`).
2. Repo Settings > Pages > Build and deployment > Source: **GitHub Actions**.
3. The workflow in `.github/workflows/deploy.yml` builds and publishes on every push.
